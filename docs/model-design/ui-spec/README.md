# UI Spec

核心页面：

| 路由 | 作用 |
|---|---|
| `/login` | Guest 登录初始化 |
| `/onboarding` | 用户画像 |
| `/today` | 今日任务与运行状态 |
| `/plans` | 计划历史 |
| `/plans/:id` | 计划、来源和任务详情 |
| `/reviews` | 复盘历史与提交 |
| `/memories` | 记忆与候选确认 |
| `/dev/runs` | Trace 开发者页 |

详见 [产品导航](./product-navigation.md) 与 [Trace 页面](./developer-trace.md)。
