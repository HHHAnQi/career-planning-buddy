# 公开能力与指标声明规范

> Status: CURRENT  
> Last verified: 2026-10-29  
> Scope: README、发布说明、演示材料与对外架构表述

## 事实优先级

当文档冲突时，按以下顺序判定当前能力：

1. 当前默认分支代码、Alembic 迁移和自动化测试；
2. `docs/architecture/current-system-overview.md`；
3. 与指定发布绑定的冻结证据包；
4. 实现基线和正式契约文档；
5. 带日期的 Review、Audit、Handoff 和历史设计文档。

历史审计仅证明对应提交和验证环境中的结论，不自动成为当前事实。

## 能力状态

公开能力只使用以下状态：

| 状态 | 含义 | 允许的表述 |
| --- | --- | --- |
| `IMPLEMENTED` | 默认路径中已实现，且有自动化测试 | “已实现” |
| `PARTIAL` | 只实现部分语义、范围或部署形态 | 必须同时说明边界 |
| `EXPERIMENTAL` | 仅在显式开关、评测或开发路径中可用 | “实验性” |
| `PLANNED` | 有设计或任务，尚未通过验收 | “计划中” |
| `NOT_SUPPORTED` | 明确不支持 | “当前不支持” |

## 量化指标

- README 的当前 Eval 通过率、延迟和 Trial 数必须来自已入库的冻结证据包；
- 发布证据必须包含数据集、模型、配置、校验和及失败分解；
- 不在 README 手工维护会随普通提交变化的测试数量；
- 历史基线没有同构证据包时，必须标注为历史对比，不与当前结果混为同一可复现结论；
- 未执行的压测、故障演练和真实用户实验不得使用“高并发”、“高可用”或“生产就绪”表述。

## 自动验证

```bash
cd backend
python -m scripts.audit_public_claims
```

该命令校验 README 的当前头条指标与冻结证据包一致，并检查当前事实和历史审计的状态标记。
