# 可重复本地验证：范围确认

## 问题

- 门禁脚本在没有项目虚拟环境时会静默使用任意全局 Python；
- 本地 Mypy 范围与 CI 和 `pyproject.toml` 中的正式范围不一致；
- 本地门禁默认使用开发数据库，与测试隔离基线冲突。

## 目标

使一个干净检出可以通过锁定依赖建立项目环境，并使 macOS/Linux、
Windows 本地门禁与 CI 使用相同的 Python 版本、Mypy 范围和测试库语义。

## 不做

- 不引入 Poetry、uv 运行时依赖或新的包管理规范；
- 不修改 CI 的锁定依赖安装方式；
- 不改变业务代码、API、数据模型或迁移；
- 不在脚本中自动下载依赖。
