# README 截图说明

根目录 README 已预留以下截图位置：

| 文件名 | 建议内容 |
|---|---|
| `workspace.png` | 工作台全景与下一步建议 |
| `materials.png` | 简历/JD 材料诊断与改写确认 |
| `interview-room.png` | 模拟面试答题与逐题分析 |
| `interview-report.png` | 面试报告、证据引用与训练动作 |
| `developer-trace.png` | Run 时间线、Tool Call 或 Eval 结果 |

建议使用一致的浏览器宽度和 16:10 或 16:9 比例，优先展示真实页面而不是拼接海报。截图前请使用虚构数据，并检查姓名、邮箱、手机号、JWT、API Key、请求 Header、Provider 控制台和真实面试内容是否已经移除。

图片准备好后，将 README 对应单元格中的占位文字替换为：

```html
<img src="docs/assets/screenshots/workspace.png" alt="Career Planning Buddy 求职工作台" width="100%">
```

其他图片只需替换文件名和 `alt` 文本。可选的 60–90 秒主流程 GIF 建议命名为 `demo.gif`，放在截图表格之后。
