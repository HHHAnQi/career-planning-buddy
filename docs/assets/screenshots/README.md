# README 截图说明

根目录 README 使用以下脱敏的 Mock Provider 演示截图：

| 文件名 | 展示内容 |
|---|---|
| `workspace.png` | 工作台全景与下一步建议 |
| `materials.png` | 简历/JD 材料诊断与改写确认 |
| `interview-room.png` | 模拟面试答题与逐题分析 |
| `interview-report.png` | 面试报告、证据引用与训练动作 |
| `developer-trace.png` | Run 时间线、Tool Call 或 Eval 结果 |

所有截图保持 1440×900，使用虚构、脱敏数据。更新截图前必须再次检查姓名、邮箱、手机号、
JWT、API Key、请求 Header、Provider 控制台和真实面试内容是否已经移除。

如后续增加 60–90 秒主流程演示，建议命名为 `demo.gif`，覆盖“建档 → 材料 → 路线 →
执行 → 面试 → 报告”的核心闭环，并在压缩体积后放到 README 首屏截图之后。
